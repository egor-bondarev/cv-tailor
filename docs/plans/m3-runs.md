Новая сессия Claude Code, вызов `/cv-tailor` с вакансией; агент без контекста разработки, только `SKILL.md` и промпты.

- **Вакансия:** senior quality engineer (тестовые фреймворки, инфраструктура, SQL).
- **Ход:** extract → route (`medium`) → вопрос пользователю, ответ «1» → analyze → tailor (1 повтор: строка skills — элемент не из словаря и превышение длины) → review → apply → отчёт → `final` по «done». Ручные шаги пользователя: выбор резюме и ревью в Docs.

- **Ревьюер:** 3 правки строк skills — `unsupported`, 2 — `partial`.
- **Расход сессии:** 50 ходов агента, 29 вызовов инструментов, ~29k выходных токенов, ~5,4M токенов чтения кэша (контекст сессии перечитывается на каждом ходе).
- **Запрещённые файлы** (`facts.json`, токены, конфиги) агент не открывал.

### Находки и изменения
1. Ревьюер не видел, чем подкреплены новые элементы строки skills (у `replace_skills` нет `evidence` по замыслу), и помечал их `unsupported`. → `review_pack` добавляет `new_items` с `basic` или фактами навыка; `review.md` объясняет, как их оценивать. Повторное ревью тех же трёх правок на живом Codex: все `supported`.
2. Агент не понял, как валидатор делит строку skills («chaos and load testing» → неизвестный элемент), и полез читать `src/`. → в `tailor.md` описан разбор строки и требование точных имён из словаря; в `SKILL.md` — не читать исходники, правила в промпте и в тексте ошибок.
3. Из двух `partial`: причинная связь «сократил … за счёт расследования сбоев» не следует из фактов (ответственность ≠ причина результата) — справедливое замечание; оставлено на ревью пользователя.
